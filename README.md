# Music Record Rental Management System (Python)

A Python-based music store rental management system developed as part of coursework at Loughborough University. The project simulates a real-world rental environment, enabling efficient management and rental of music records across multiple formats.

## Project Overview

This system was designed to manage the rental of **CDs, vinyl records, and cassette tapes**, allowing users to search, view availability, and manage inventory effectively. The focus of the project was on applying core Python programming concepts, data handling, and visualisation techniques within an interactive environment.

## Features

- Supports multiple music formats:
  - CDs
  - Vinyl
  - Cassette tapes
- Rental and availability tracking for each record
- Comprehensive search functionality to filter records by:
  - Artist
  - Title
  - Medium
  - Genre
- Displays detailed record information and current availability status

## Technical Implementation

- Implemented using **arrays and functions** to store and manage music records  
- Used Python data structures for inventory management  
- Applied **file handling** to persist rental and inventory data  
- Implemented inventory pruning and availability analysis using **Matplotlib** for visualisation  
- Visual feedback helps identify stock levels and manage popular items effectively  

## Interactive Development Environment

- Developed and presented using **Jupyter Lab**
- Interactive notebook structure with:
  - Clear documentation
  - Executable cells for searching, renting, and managing records
  - Visual output for inventory analysis
- The notebook format improves readability, maintainability, and ease of experimentation
